# Risks

WebMCP API/support changes: isolate adapter, follow current primary docs, keep human fallback. Dynamic discovery timing: show availability, clean up correctly, avoid instant-discovery claims. Agent variability: deterministic tests plus fixed eval prompts and recorded stable run. Scope creep: milestones/locked decisions. Security overclaim: state app enforcement—not agent identity attestation. Demo fragility: deterministic external-update simulator. Hosting complexity: one origin, seed data, no secrets. Semantic ambiguity: persistent selection-versus-delegation UI.
