# UX specification

Single workbench: header (session/revision/WebMCP/reset), customer selection, shared staged changes, active mandate/delegate/revoke panel, capability inspector, validation/conflict panel, provenance timeline. States: NO_MANDATE, ACTIVE_MANDATE, DRAFT, VALIDATED, READY_FOR_APPLY, STALE, REVISION_CONFLICT, POLICY_CHANGED, APPLIED, WEBMCP_UNAVAILABLE. Persistent language distinguishes “selected” from “delegated”; apply is a visually separate human action.
