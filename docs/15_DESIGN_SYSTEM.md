# Design system

Use a focused workbench. Authority is neutral when absent and clearly accented when active, always with exact scope chips. Pair every state color with a label. Changes show before → after, base revision, actor, and validation. Human/agent provenance gets distinct labels/icons. Apply is isolated and disabled for invalid/stale work. Inspector mirrors registered name, description, inputs, and availability. Favor small transparent state transitions over decorative “AI” imagery.
