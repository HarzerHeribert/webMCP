# Design system

Use a focused workbench. Authority is neutral when absent and clearly accented when active, always with exact scope chips. Pair every state color with a label. Changes show before → after, base revision, actor, and validation. Human/agent provenance gets distinct labels/icons. Apply is isolated and disabled for invalid/stale work. Inspector mirrors registered name, description, inputs, and availability. Favor small transparent state transitions over decorative “AI” imagery.

**Register.** Enterprise SaaS, light: the surface a revenue team already works
on. The argument only lands if the host reads as real software, so Relay CRM
borrows the conventions of the products it stands in for — white record cards on
a tinted page, a blue primary for ordinary interaction, near-flat elevation, one
eyebrow type size, and a full-width activity rail beneath the work.

**The one reserved colour.** Blue is interaction. Amber is authority, and nothing
else. A delegated record gets an amber accent bar; a scope chip, a live mandate
panel and the Delegate control are amber; every other control on the screen is
not. This is what makes "the human granted something, and it is live right now"
visible without a caption.
