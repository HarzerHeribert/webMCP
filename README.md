# Mandate

Mandate turns a human’s explicit, temporary browser-session intent into a live, bounded WebMCP capability surface. Relay CRM is the host demo—not the product. The agent stages changes; the human applies them. Dynamic schemas communicate authority and the backend enforces it.

See [agent guidance](AGENTS.md) and [docs](docs/00_PRODUCT_THESIS.md). `FIRST_AGENT_PROMPT.md` is deliberately absent.
